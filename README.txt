SHADOW BORN AI - VERSION 2 PWA STARTER

WHAT THIS IS
This is an installable Progressive Web App (PWA) starter. It includes the chat interface, app manifest, install button, app icons, and offline shell caching. It does NOT yet have a connected AI model.

INSTALL ON ANDROID
1. Upload every file in this folder to the root of a public HTTPS website. GitHub Pages is one option.
2. Open the website in Chrome on Android.
3. Tap Install app if the button appears. If it does not, open Chrome's three-dot menu and choose Install app or Add to Home screen.

IMPORTANT
Do not place a private AI API key in index.html. A secure backend is needed for real AI replies. The app shell can open offline after it has been loaded, but AI replies need internet and a connected backend.
